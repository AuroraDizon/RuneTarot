# RuneTarot

Draw from the 78-card Rider-Waite-Smith tarot, then cast an Elder Futhark rune beside any card to clarify what it is saying.

- One card, Past · Present · Future, or the Celtic Cross
- Short and fuller meanings for every card and rune, upright and reversed (card and rune reversals are optional)
- A journal for your readings, with notes, kept privately in your own browser
- An optional crackling hearth

Everything runs in the browser. Nothing is sent anywhere.

## Publish on GitHub Pages

1. Create a new repository (for example `RuneTarot`) and upload everything in this folder, keeping the `cards` folder as it is.
2. In the repository, open **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save.
3. After a minute the site is live at `https://<your-username>.github.io/RuneTarot/`.
